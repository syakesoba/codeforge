ページ・コンポーネント

  • Next.js 16 (App Router, TypeScript, Tailwind CSS v4)
  • app/page.tsx: トップページ。全コース・全レッスンへのリンク一覧
  • app/login/page.tsx / app/signup/page.tsx: 認証ページ（中身は共通の AuthForm）
  • app/lessons/[id]/page.tsx: サーバーコンポーネント。ページ表示時にバックエンドの GET /api/problems/{id} を取得し、LessonWorkspace に渡す。ヘッダーに「← レッスン一覧に戻る」リンクとコース内の位置（例:「レッスン 3/6」）を表示
  • components/AuthProvider.tsx: 認証状態・進捗・ストリークを管理するContext。
    • マウント時に GET /api/me でログイン状態を確認し、ログイン中なら GET /api/progress も取得する
    • 合格済みレッスンの情報源を切り替える: ログイン中はサーバー、未ログインはlocalStorage
    • 合格日時（passedAt）も同様にサーバー/localStorageを切り替えて保持し、lib/streak.tsで連続学習日数を算出する
  • components/LessonWorkspace.tsx: クライアントコンポーネント。
    • 左ペイン: SlideViewer で問題文をスライド形式に表示
    • 右ペイン: @uiw/react-codemirror + @codemirror/lang-go によるGoシンタックスハイライト付きエディタ。@codemirror/lint によるリアルタイムエラー検知・importクイックフィックスも統合済み
    • レッスンを開くと保存済みの下書き（サーバー or localStorage）を復元し、入力停止1.2秒後に自動保存する
    • 「実行して採点」ボタン押下で POST .../submit を呼び、pass/fail・所要時間・実行結果ログ（fmt.Println等の標準出力を含む、go testの生出力）を表示。合格時は進捗を記録して SuccessModal を表示
    • 「フォーマット」ボタン押下で POST .../format を呼び、import整理・gofmt整形済みのコードでエディタを置き換える
    • 「答えを見る」ボタン押下で GET .../answer を呼び、模範解答コードを表示（再度押すと隠す。一度取得した内容はキャッシュして再取得しない）
  • components/SuccessModal.tsx: 合格時のポップアップ。「次のレッスンへ進む →」で次のレッスンに遷移する（最終レッスンではコース制覇の表示になる）
  • components/LessonList.tsx: コース別のレッスン一覧。合格済みレッスンの右側にチェックマーク、各コースカードにProgressBarを表示する
  • components/ProgressBar.tsx: 合格数/総数を受け取って描画する汎用の進捗バー。ヘッダー・コース一覧・レッスンページの3箇所で共用する
  • components/StreakBadges.tsx: トップページに表示するストリーク日数とバッジの一覧。lib/badges.tsのcomputeEarnedBadgesで導出する
  • components/SlideViewer.tsx: クライアントコンポーネント。lib/slides.ts の splitIntoSlides で問題文Markdownを ## / ### 見出し単位のスライド配列に分割し、前へ/次へボタン・ドットインジケーターでページ送りする（Progateのスライド画面を意識したUI）

lib（ロジック・APIクライアント）

  • lib/slides.ts: Markdownをスライドに分割するパーサー。フェンス付きコードブロック内の # 始まりの行は見出しとして扱わない
  • lib/lessons.ts: コース・レッスンの定義と順序。「次のレッスン」の解決もここが担当する
  • lib/streak.ts: 合格日時の配列から連続学習日数を計算する純粋関数
  • lib/badges.ts: 合格済みレッスンとストリーク日数からバッジ一覧を導出する純粋関数
  • lib/draft.ts: 未ログイン時のコード自動保存（localStorageのみ）
  • lib/progress.ts: 未ログイン時の進捗（localStorage）。{ [problemId]: 合格日時ISO } の形式で保持する
  • lib/api.ts: NEXT_PUBLIC_API_BASE_URL（デフォルト http://localhost:8080）を参照するAPIクライアント。認証が絡むリクエストには credentials: "include" を付ける
react-markdownは生HTMLを描画しない

問題文のMarkdown内に生の <div> タグ等を書いても、rehype-raw を追加しない限り react-markdown は描画しない（黙って消える）。 注意書きなどを強調したい場合はMarkdown標準の引用（> ）を使うこと。Lesson 4の「重要な注意点」もこの理由で引用ブロックに書き直している。
