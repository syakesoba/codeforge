CodeForge

コードを書いて実行しながら学ぶ、Progate風のプログラミング学習サイト。 第一弾はGoの応用編（Web API・DB連携・認証・並行処理）を扱う。

現在地点 全5コース27レッスン＋ユーザー認証・学習進捗の保存に加え、エディタのimportクイックフィックスやCSRF/レート制限/採点キューイングも実装済み。 「新コース追加」（Course 6〜9: テストの書き方・エラーハンドリング・実践的なアーキテクチャ・デプロイ/Docker化、各全5レッスン）もすべて完了した。 残るは本番デプロイのみ。 詳細は 実装プラン を参照。

 Setup

起動方法

ローカル環境でバックエンド・フロントエンドを立ち上げて動作確認するための手順。

プロジェクトの前提

  • 対象言語: Go（他言語経験者向け、応用編に特化。基礎文法は扱わない）
  • バックエンド: Go / フロントエンド: Next.js（React）
  • コード実行: Dockerサンドボックス内で go test による自動採点
  • ホスティング: 将来的にクラウド（AWS/GCP等）での本格運用を想定
  • リポジトリ: github.com/syakesoba/codeforge
