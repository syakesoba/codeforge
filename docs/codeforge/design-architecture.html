全体構成・ディレクトリ構成

ブラウザ〜フロントエンド〜バックエンドの全体図と、リポジトリのディレクトリ構成。

詳細設計トップ 全体構成 採点フロー エディタ・学習体験 認証・進捗 API仕様 フロントエンド構成 セキュリティ

全体構成

[ブラウザ]
   │  GET /lessons/[id]  (SSRでバックエンドから問題データ取得)
   │  POST 採点リクエスト (クライアントから直接、CORS経由・Cookie付き)
   ▼
[Next.js frontend :3000]
   │  fetch (NEXT_PUBLIC_API_BASE_URL, credentials: include)
   ▼
[Go backend :8080]  cmd/server/main.go
   │  GET  /api/problems/{id}          問題文・雛形コードを返す
   │  GET  /api/problems/{id}/answer   模範解答を返す
   │  POST /api/problems/{id}/submit   ユーザーコードを採点する（Docker）
   │  POST /api/problems/{id}/check    コンパイルエラーを検知する（ホスト直接実行）
   │  POST /api/problems/{id}/format   import自動修正・gofmt整形（ホスト直接実行）
   │  POST /api/auth/signup|login|logout
   │  GET  /api/me, /api/progress      認証状態・学習進捗
   ├───────────────┬─────────────────┐
   ▼                                    ▼                                    ▼
[internal/judge]                   [internal/lint]                     [internal/auth] → [internal/store]
   │  一時ワークスペース作成            一時ワークスペース作成               セッション検証     SQLite
   │  → docker run → 結果パース         → go build のみ実行（サンドボックス不要） 合格時に進捗を記録  (data/codeforge.db)
   ▼
[Docker: codeforge-judge イメージ]
   go test -vet=off -json ./...  を実行し、結果を標準出力(JSON)で返す

ディレクトリ構成

go_study/                          (リポジトリルート, module github.com/syakesoba/codeforge)
  go.mod
  cmd/server/
    main.go                        HTTPサーバーのエントリポイント・問題/採点エンドポイント
    authhandlers.go                サインアップ/ログイン/ログアウト/me/progress
    drafthandlers.go               コード自動保存の取得/保存
    csrf.go                        Double Submit CookieによるCSRF対策
    ratelimit.go                   クライアントIP取得・レート制限ミドルウェア
  internal/judge/
    judge.go                       サンドボックス実行のオーケストレーション・同時実行数の制御（キューイング）
    docker.go                      docker run 呼び出し（exec.CommandContext）
    result.go                      `go test -json` 出力の整形（表示用）
  internal/lint/
    lint.go                        go build のみを実行するエディタ向けエラー検知（/check）
    format.go                      goimports相当のimport自動修正（/format）
  internal/problems/
    problems.go                    problemID -> ディレクトリ の許可リスト・ロード処理
  internal/auth/
    auth.go                        サインアップ・ログイン・セッション管理（bcrypt）
  internal/ratelimit/
    ratelimit.go                   キー単位の固定ウィンドウ方式レート制限（インメモリ）
  internal/store/
    store.go                       SQLite（users / sessions / progress / code_drafts）
  problems/
    concurrency/                   Course 1: ゴルーチン・並行処理（6レッスン）
    web-api-basics/                Course 2: Web APIの基礎（6レッスン）
    gin-api/                       Course 3: フレームワークで作るAPI（5レッスン）
    database/                      Course 4: データベース連携（5レッスン）
    auth-jwt/                      Course 5: 認証・JWT（5レッスン）
      05-capstone-login-api/       ← 各レッスンは以下の5ファイルで構成
        problem.md                 スライドの元になる説明文（Markdown）
        starter.go                 ユーザーに見せる雛形コード
        answer.go                  模範解答（`//go:build ignore`でビルド対象外）
        solution_test.go           非公開の採点用テスト（クライアントには渡さない）
        go.mod / go.sum            採点ワークスペースに配置する依存定義
  judge-image/
    Dockerfile                     採点用サンドボックスイメージ
    priming/                       Gin/GORM/SQLite/JWTのキャッシュを焼き込むための捨てモジュール
  data/codeforge.db                アプリのSQLite（.gitignore対象。初回起動時に自動生成）
  frontend/                        Next.js（App Router, TypeScript, Tailwind CSS v4）
    src/app/page.tsx               トップページ（コース・レッスン一覧）
    src/app/login|signup/page.tsx  ログイン・新規登録ページ
    src/app/lessons/[id]/page.tsx  レッスンページ（サーバーコンポーネント）
    src/components/                詳細は「フロントエンド構成」ページ参照
    src/lib/                       詳細は「フロントエンド構成」ページ参照
  docs/
    requirements.md                初期要件メモ
    codeforge/                     このドキュメント一式
このドキュメントはCodeForgeの機能追加に合わせて更新されます。
